# Türkiye GeoJSON Harita Verisi / Turkey GeoJSON Map Data

Bu dizinde yer alan `turkey.geojson` dosyası, Türkiye'nin 81 il sınırlarını içeren açık kaynaklı vektör sınır verisidir.

## Kaynak ve Lisans / Source & License
- **Veri Kaynağı**: Açık kaynak Türkiye İl Sınırları GeoJSON (Alper S. / GitHub repository: Turkey-Maps-GeoJSON)
- **Format**: GeoJSON FeatureCollection (WGS84 EPSG:4326 koordinat sistemi: [boylam, enlem])
- **Kullanım**: Anadolu Tarihöncesi Atlası ("Prehistoric Anatolia Atlas") web uygulaması için yerel, çevrimdışı ve hiçbir harici API/servis anahtarı gerektirmeyen vektör harita altlığı.
- **İçerik**: 81 il idari sınır poligonları, tam boylam ve enlem sınır çizgileri.
